# Aprendizados

## 2026-09-09
- A instrução inicial é suficiente para preparar o repositório; não é necessário aguardar o planejamento para criar a base documental.
- Os pilares informados não definem contratos ou implementação. Esses detalhes devem vir do planejamento aprovado.
- Continuidade exige leitura prévia de `AGENTS.md`, `PROJECT_STATE.md` e `HANDOFF.md`, com atualização dos registros ao encerrar cada sessão.
- Git local não define privacidade: o repositório remoto deverá ser criado como privado no GitHub.
