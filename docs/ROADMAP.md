# Roadmap

Este roteiro organiza a continuidade e não substitui o planejamento aprovado.

## Etapa 0 — preparação autorizada
- Inicializar Git em `main`.
- Criar documentação, instruções de continuidade e arquivos de configuração de exemplo.
- Verificar ausência de segredos, revisar arquivos e fazer o primeiro commit local.
- Deixar documentada a conexão futura com GitHub privado.

## Próximas etapas — dependem do planejamento e de nova solicitação
1. Incorporar o planejamento aprovado e consolidar escopo, critérios de aceite e decisões de arquitetura.
2. Detalhar Product DNA, Brand DNA, Creative DNA, Prompt Compiler e Model Router.
3. Definir as integrações de imagens e a extensão para novos modelos e provedores.
4. Planejar Supabase/PostgreSQL, Cloudflare R2 e Workers/Queues.
5. Implementar, validar e entregar por incrementos conforme o planejamento.

Nenhuma implementação funcional foi autorizada nesta preparação.
